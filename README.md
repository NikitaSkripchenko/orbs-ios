# ThinkingOrbsKit

Native SwiftUI ports of the nine dotted thought-orb animations from [thinking-orbs](https://github.com/Jakubantalik/thinking-orbs).

ThinkingOrbsKit is under active development. Version 0.1 targets iOS 15 and later and will provide both upstream tuned sizes, automatic light/dark rendering, speed and pause controls, Reduce Motion behavior, and accessibility labels.
